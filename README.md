# technika_registration_v.2 — Previous Iteration (v2)

Second iteration of the Technika event registration backend.

## What This Repository Was

This was the second iteration of the Technika registration backend, building on the first version with the same general architecture: Node.js/Express, MongoDB, Mongoose, Google Sheets sync, team management, and PDF receipt generation.

It was superseded by the current registration platform.

## Project Status

This repository is a **previous iteration** and is not the current Technika registration platform.
